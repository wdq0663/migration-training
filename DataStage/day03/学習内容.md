## 二、Oracle 接続設定学习内容

### 1. 使用的 Connector 类型

在本次练习中，使用 **Oracle Enterprise Connector Stage** 进行数据库连接。

选择理由如下：

* Oracle 官方原生连接方式
* 性能优于 ODBC
* 企业项目中使用最广泛
* 支持 INSERT / SELECT / SQL 模式操作

---

### 2. Oracle 连接方式说明

本次连接采用 **EZCONNECT** 方式，不使用 `tnsnames.ora` 文件。

连接格式如下：

```
{hostname}:{port}/{service_name}
```

示例：

```
oracle-db.company.co.jp:1521/ORCLPDB1
```

---

### 3. Oracle 接続設定书（提交用）

```text

端口（Port）: 1521
服务名（Service Name）: ORCLPDB1
用户名（Username）: HR
Schema: HR

连接测试结果: 成功
```

## 三、作业 2：CSV → Oracle 数据加载作业

### 1. 作业目标

将 CSV 文件中的员工数据，通过 DataStage 加载到 Oracle 表 `EMPLOYEES` 中。

---

### 2. Job 结构设计

```text
Sequential File → Transformer → Oracle Enterprise
```

* **Sequential File**：读取 CSV 文件
* **Transformer**：字段清洗与数据类型转换
* **Oracle Enterprise**：向 Oracle 表执行 INSERT

---

### 3. Transformer 中的字段转换规则

| CSV 字段     | Oracle 字段  | 转换处理                             |
| ---------- | ---------- | -------------------------------- |
| emp_id     | EMP_ID     | 原样输出                             |
| emp_name   | EMP_NAME   | TRIM(emp_name)                   |
| department | DEPARTMENT | 原样输出                             |
| hire_date  | HIRE_DATE  | TO_DATE(hire_date, 'YYYY-MM-DD') |
| salary     | SALARY     | TO_DECIMAL(salary)               |
| manager_id | MANAGER_ID | 原样输出                             |

说明：

* DataStage 中不支持 SQL 的 `CAST`、`UPPER` 等函数
* 日期与数值必须使用 DataStage 专用函数进行转换
* Oracle 表中 `CREATED_AT`、`UPDATED_AT` 字段使用默认值，不需传入

---

### 4. 执行结果验证

执行完成后，通过以下 SQL 验证数据是否成功插入：

```sql
SELECT COUNT(*) FROM EMPLOYEES;
```

结果为 **8 条记录**，说明 CSV 数据已成功加载至 Oracle。

## 四、作业 3：Oracle → CSV 数据导出作业

### 1. 作业目标

从 Oracle 数据库中查询「営業部」的员工信息，并导出为 CSV 文件。

---

### 2. 使用的 SQL 查询语句

```sql
SELECT
    EMP_ID,
    EMP_NAME,
    DEPARTMENT,
    TO_CHAR(HIRE_DATE, 'YYYY-MM-DD') AS HIRE_DATE,
    SALARY
FROM EMPLOYEES
WHERE DEPARTMENT = '営業部'
ORDER BY HIRE_DATE;
```

说明：

* 日期格式在 SQL 中使用 `TO_CHAR` 处理
* WHERE 条件用于部门过滤
* ORDER BY 用于排序结果

---

### 3. 输出结果确认

成功生成 CSV 文件，内容如下：

```csv
EMP_ID,EMP_NAME,DEPARTMENT,HIRE_DATE,SALARY
E001,山田太郎,営業部,2020-04-01,450000
E005,伊藤健一,営業部,2022-03-01,350000
E008,小林恵子,営業部,2023-01-16,320000
```

## 五、作业 4：数据类型映射验证

### 1. 验证目的

确认 DataStage 与 Oracle 之间的数据类型映射是否正确，特别是以下类型：

* VARCHAR2
* NUMBER
* DATE
* TIMESTAMP
* CLOB

---

### 2. 数据类型映射总结

| Oracle 类型 | DataStage 类型 |
| --------- | ------------ |
| VARCHAR2  | string       |
| NUMBER    | decimal      |
| DATE      | date         |
| TIMESTAMP | timestamp    |
| CLOB      | string       |

通过 CSV 加载测试数据后，所有字段均能正确写入 Oracle，未发生编码或类型错误。
