# WordPress企业官网制作 Demo｜成果发表

## 1. 项目背景与目标（约1分钟）

本项目是一个 IT 企业官网的制作 Demo，目标是使用 WordPress 从零开始，完整实践一个企业网站的标准制作流程。

项目的核心目标包括：
- 构建结构清晰的企业官网（TOP / Service / Company / Contact）
- 使用 WordPress 的标准功能，而非过度定制
- 兼顾设计、可维护性与 SEO 基础设置
- 最终形成可交付、可复用的成果物与文档

整个项目在本地环境中完成，模拟真实企业网站开发流程。

---

## 2. 网站整体结构与设计思路（约1分钟）

### 网站结构

网站由以下 4 个固定页面构成：

- TOP：传达企业形象 + 引导咨询
- Service：介绍提供的服务内容
- Company：展示公司信息，增强信任感
- Contact：提供咨询入口，促进转化

采用简洁的菜单结构，避免信息过载，符合日本企业官网的常见设计模式。

---

### 导线设计

用户导线的核心思路是：
- 从任何页面都可以轻松进入 Contact 页面
- TOP 页面设置多个 CTA
- Service 页面自然引导至咨询

---

## 3. 本次项目中重点下功夫的 3 个地方（约1.5分钟）

### ① 主题选择与定制的平衡

在多个免费主题中进行比较后，选择了更适合企业站的主题，并通过：

- Customizer 设置品牌色与字体
- 最小限度的自定义 CSS
- 避免过度依赖插件

确保网站既有设计感，又保持了可维护性。

---

### ② SEO 的基础但完整的设置

本项目并未追求高级 SEO，而是注重“基础但规范”：

- 为所有页面设置 Meta Description
- 生成并确认 XML Sitemap
- 设置 OGP 信息，确保 SNS 分享展示正常

重点在于：**理解每一项设置的意义，而不是只完成操作**。

---

### ③ 可用性优先的联系表单设计

在 Contact 页面中，重点关注：

- 必须项的明确提示
- 表单验证的正常工作
- 移动端输入体验
- 自动回复邮件设置

将“能顺利完成咨询”作为第一优先级。

---

## 4. 咨询转化（CTA）方面的设计（约1分钟）

为了提升咨询转化率，采取了以下措施：

- TOP 页面至少 2 处 CTA 按钮
- 使用降低心理门槛的按钮文案  
  例如：「まずはお気軽にご相談ください」
- 从 Service 页面自然引导到 Contact 页面

避免只在 Contact 页面“孤立地”放一个表单。

---

## 5. 项目过程中遇到的问题与解决（约1分钟）

### 表单邮件问题
- 本地环境无法直接发送真实邮件
- 通过工具确认逻辑正常，并在文档中明确线上需配置 SMTP

### CSS 不生效问题
- 通过 DevTools 确认真实选择器
- 提高选择器精度解决问题

### 移动端布局问题
- 使用 Chrome DevTools 进行设备模拟
- 针对移动端进行样式微调
