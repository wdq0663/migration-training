# Best Practices - WordPress企业网站制作总结

## 1. 项目概述

本项目为一个 IT 企业官网 Demo，使用 WordPress 在本地环境中完成，从环境搭建、页面结构设计、主题定制、SEO 设置到最终优化与交付，完整经历了一个企业网站的制作流程。

目标是：
- 构建一个结构清晰、可维护的企业网站
- 实践 WordPress 在企业官网中的标准用法
- 总结可复用的制作经验与注意事项

---

## 2. 三个技术层面的核心收获

### ① 固定页面在企业站中的正确用法

通过本次实践，明确了固定页面（Page）在企业网站中的核心地位：

- TOP / Service / Company / Contact 均应使用固定页面
- URL 结构稳定，适合 SEO
- 便于菜单管理和内容长期维护

👉 企业站 **几乎不使用“投稿（Post）”作为主页面**。

---

### ② SEO 插件不是“装了就行”，而是要“逐页配置”

在使用 Yoast SEO 的过程中，认识到：

- 每个页面都需要单独设置：
  - Meta Title
  - Meta Description
- XML Sitemap 需要确认已生成并可访问
- OGP 设置直接影响 SNS 分享效果

👉 SEO 是**配置工作，不是一次性安装行为**。

---

### ③ Contact Form 的可用性比“样子”更重要

制作表单时，真正重要的是：

- 必须项是否清晰
- 错误提示是否明确
- 邮件是否真的能送达
- 手机端输入是否顺畅

👉 表单 = 转化入口，**稳定性优先于设计感**。

---

## 3. 三个踩坑点 & 对应解决方案

### ❌ 坑 1：表单提交成功但收不到邮件

**原因**
- 本地环境（Local by Flywheel）默认不发送真实邮件

**解决方案**
- 使用 MailHog 查看测试邮件
- 文档中明确标注：线上环境需配置 SMTP 插件

**经验总结**
> 表单测试要关注“系统逻辑是否正确”，而不是只看邮箱。

---

### ❌ 坑 2：自定义 CSS 不生效

**原因**
- CSS 选择器权重不足
- 未正确命中主题结构

**解决方案**
- 使用浏览器 DevTools 定位真实 class
- 必要时提高选择器精度

**经验总结**
> 写 CSS 前，一定先看 DOM 结构。

---

### ❌ 坑 3：PC 正常，手机端布局错乱

**原因**
- 未考虑移动端显示
- 固定高度、过大 padding 导致溢出

**解决方案**
- 使用 Chrome DevTools 设备模拟
- 针对移动端添加 media query

**经验总结**
> 企业官网 **必须移动端优先检查**。

---

## 4. WordPress 企业网站制作的实用技巧

### ✅ 1. CTA 一定要“重复出现”

- TOP 页面至少 2 处 CTA
- Service 页面引导至 Contact
- 按钮文案要“降低心理门槛”

例：
- 「まずはお気軽にご相談ください」
- 「無料でご相談いただけます」

---

### ✅ 2. 菜单结构要“少而清晰”

推荐结构：
- TOP
- Service
- Company
- Contact

👉 企业站不是信息站，**不要菜单过多**。

---

### ✅ 3. 公司信息要传达“安心感”

Company 页面必须清楚展示：
- 公司名称
- 所在地
- 联系方式
- 业务内容

👉 对用户来说，“可信度”比“设计炫酷”更重要。
